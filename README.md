

# AI-Powered Dashboard Automation Agent

## Project Overview

This project focuses on building an AI-powered workflow automation agent using n8n to automate the dashboard development workflow and support data visualization through Metabase.

The project combines workflow automation, AI agent capabilities, Docker, and business intelligence tools to reduce repetitive manual tasks involved in data analysis and dashboard creation.

## Technologies Used

- n8n – Workflow automation
- AI Agent – AI-assisted workflow execution
- Metabase – Dashboard creation and data visualization
- Docker – Containerized environment
- Python – Data processing and analysis
- SQL – Data querying and analysis

## Project Objectives

- Automate repetitive data workflow tasks.
- Integrate AI capabilities into workflow automation.
- Support dashboard creation using Metabase.
- Connect data processing and visualization workflows.
- Reduce manual effort in reporting and dashboard development.

## Workflow Overview

1. Data and workflow inputs.
2. n8n workflow execution.
3. AI agent processing.
4. Automation and integration steps.
5. Metabase dashboard visualization.

## Key Skills Demonstrated

- AI Agent Development
- Workflow Automation
- Data Visualization
- Dashboard Automation
- Docker Environment Management
- Data Workflow Integration
